MyDiary プライバシーポリシー

最終更新日：2026年11月25日

MyDiary（以下「本アプリ」）は、作者が個人で使うために作った iPad 用の手帳アプリです。配布はしていません。本アプリが扱う情報と、その扱い方を次のとおり定めます。

1. 利用する Google のデータ

本アプリは、利用者が許可した Google アカウントについて、次の範囲だけを利用します。

  • Google カレンダーの予定の読み取り・作成・変更・削除（calendar.events）
  • Google カレンダーのカレンダー一覧の読み取り（calendar.calendarlist.readonly）

カレンダー自体の作成や削除、共有設定の変更、Gmail など他のサービスのデータには触れません。

2. データの保存場所

  • 予定の写し（件名・日時・カレンダー）は、表示のために利用者の iPad の中だけに保存します。説明欄や場所は保存しません。
  • Google へのログイン情報（トークン）は、利用者の iPad のキーチェーンに保存します。
  • 手書きのノートは、利用者自身の iCloud（Apple の CloudKit の個人領域）に保存します。

本アプリは独自のサーバーを持たず、作者を含む第三者にデータを送ることはありません。

3. 第三者への提供・広告

取得したデータを第三者に販売・提供したり、広告に使ったりすることはありません。

4. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。

5. データの削除

本アプリの設定から Google アカウントの接続を解除すると、そのアカウントの予定の写しとログイン情報を iPad から消し、Google 側の許可も取り消します。本アプリを削除すると、iPad の中のデータも消えます。Google アカウントの「サードパーティ製のアプリとサービス」の画面からも、いつでも許可を外せます。

6. 改定

本ポリシーを改定するときは、このページを更新し、最終更新日を改めます。
